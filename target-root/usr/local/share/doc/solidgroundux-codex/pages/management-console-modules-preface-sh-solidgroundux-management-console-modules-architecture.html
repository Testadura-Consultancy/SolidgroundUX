management-console-modules_preface.sh::SolidGroundUX Management Console Modules:Architecture:

The Management Console Modules are implemented as a collection of shell scripts, that all reside in a directory. sgnd-console is the host application which takes a paramaeter to load a module or all modules in a directory. This directory defaults to usr/local/libexec/solidgroundux/console-modules. The actual module scripts are named with a two-digit prefix to control the order in which they are loaded, the consist mostly of menuregistration calls, and mayube a little local helper. These menu registrations call a separate executable, that handles the actual work. The 'action' scripts are selfcontained executables and leverage SolidGroundUX and could be called outside sgnd-console
