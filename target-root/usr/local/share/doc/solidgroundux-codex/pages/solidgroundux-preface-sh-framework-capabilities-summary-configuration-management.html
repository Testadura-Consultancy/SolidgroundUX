Configuration management
solidgroundux_preface.sh::Framework capabilities summary:Configuration management:

The configuration system provides a reusable way to read and manage configuration values for scripts and framework components. It helps keep operational settings outside the script body while still making them accessible through standard framework calls.

Use configuration support when a value should be user-editable, environment- specific, or shared across multiple scripts. This is generally preferable to hardcoding local paths, defaults, and behavior switches throughout a script.
