SDK templates
solidgroundux_preface.sh::Framework capabilities summary:SDK templates:

The SDK templates provide starting points for executable scripts, reusable libraries, and console modules. They encode the expected module header, bootstrap, guard, documentation, and entry-point structure.

Use templates when starting new SolidGroundUX components. This keeps new code aligned with the framework conventions and reduces the amount of structural code that has to be recreated manually.
