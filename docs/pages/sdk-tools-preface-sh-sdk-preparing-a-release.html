Preparing a Release
sdk tools_preface.sh::SDK:Preparing a Release:

prepare-release.sh creates the complete release set consumed by the standalone release manager. It can maintain Version and Build metadata, refresh changed-file checksums, verify executable wrappers, optionally create missing wrappers, and generate the archive, manifest, removal manifest, and checksum sidecars.

The prepared bundle includes release-manager.sh so a fresh machine can bootstrap from the same framework-independent lifecycle used for later updates and rollback. release-manager.sh then owns check, download, install, update, rollback/reinstall, and removal operations.
