_sgnd_flag_is_on Purpose:

Evaluate whether a framework flag value represents a logical true state.

Arguments:

$1 Value to evaluate.

Returns:

0 for 1, true, yes, or on (case-insensitive variants currently supported).
1 otherwise.

Usage:

_sgnd_flag_is_on "${FLAG_DRYRUN:-0}"
