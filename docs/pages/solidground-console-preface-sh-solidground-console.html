SolidGround Console
solidground console_preface.sh:::SolidGround Console:

The SolidGround Console is the reusable application host that powers the SolidGroundUX Management Studio. The host provides menu registration, rendering, paging, runtime state, action dispatch, and module loading. Applications are composed from source-only console modules rather than hard-coded into the host.

The Management Studio uses the same console recursively: the main console loads a small set of launcher modules, and each launcher opens another sgnd-console instance with the module set that defines its submenu. The same menu engine, themes, state indicators, paging, and dispatch logic are therefore reused at every level.
