Architecture
solidground console_preface.sh::SolidGround Console:Architecture:
sgnd-console
│
├─ Main menu module set
│ ├─ Computer Management
│ ├─ Active Directory
│ ├─ File Services
│ ├─ SolidGroundUX Setup
│ ├─ Development
│ └─ Console Settings
│
└─ selected launcher
│
└─ sgnd-console
│
└─ submenu module set
│
└─ registered groups and actions
│
└─ public/private executables

The important boundary is ownership: sgnd-console owns menu mechanics; modules own menu content. A submenu is not a second menu implementation. It is another use of the same console host with a different module source.
