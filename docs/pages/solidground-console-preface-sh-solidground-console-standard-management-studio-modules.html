Standard Management Studio Modules
solidground console_preface.sh::SolidGround Console:Standard Management Studio Modules:

The standard Management Studio is currently composed of two primary modules.

Framework Configuration provides:

• installation and upgrades
• framework configuration
• framework state
• logging
• diagnostics
• developer tools

Machine Configuration provides:

• machine identity
• network configuration
• SSH management
• template preparation
• package maintenance
• optional server roles

The host itself contributes the Console Session group containing runtime and navigation actions.
