Design Philosophy
solidground console_preface.sh::SolidGround Console:Design Philosophy:

The console host deliberately contains no business logic and no knowledge of Active Directory, storage, package management, or other functional domains. Its responsibility is to provide a reusable execution and presentation engine.

The governing rule is:

Modules own menus; the framework owns menu mechanics.

This makes submenu support a composition problem rather than a new UI feature. The same host can render the main menu, a functional submenu, or an entirely different console application simply by changing the modules it loads.
