Host and Application Identity
solidground console_preface.sh::SolidGround Console:Host and Application Identity:

The executable defaults to the neutral identity `sgnd-console`. A module may optionally define `SGND_CONSOLE_TITLE_OVERRIDE` and `SGND_CONSOLE_DESC_OVERRIDE` while it is being sourced.

Only the first successfully loaded module may apply these values. Module files are loaded in sorted filename order, so numeric filename prefixes provide an explicit and visible application startup order:

10-sgnd-config.sh
20-machine-config.sh
30-customer-extension.sh

The filename controls load order only. The stable module identity remains the value declared through `SGND_MODULE_ID`.
