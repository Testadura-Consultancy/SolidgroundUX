Paging and Rendering
solidground console_preface.sh::SolidGround Console:Paging and Rendering:

Menu registrations are stored in datatables but rendered from cached page models.

The menu engine materializes direct-index caches for groups and items, computes visible entries, and builds page layouts only when necessary.

Interactive redraws therefore avoid repeated traversal of the registration data, providing consistent performance even as the number of modules grows.
