SolidgroundUX / solidground console_preface.sh / SolidGround Management Console / Architecture
sgnd-console
│
├─ discovers enabled module files
│ │
│ └─ reads literal page metadata only
│
├─ renders main index
│
└─ selected page
│
├─ source module once when first opened
├─ module registers groups and items
├─ render only registrations from that module
└─ Esc returns to the main index

This page-level lazy-loading model keeps initial console startup small while preserving self-contained functional modules. Implementation code is parsed only when the corresponding page is actually used.
