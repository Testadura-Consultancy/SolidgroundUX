SolidGroundUX / 45-solidground-framework-test.sh / Console registration

Provides one central testing and validation surface for SolidGroundUX. The framework smoke tester remains responsible for interactive framework/UI tests, while this module adds structural installation and console checks and delegates service-specific validation to the modules that own those services.
