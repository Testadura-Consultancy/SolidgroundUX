Metadata Management
sdk tools_preface.sh::SDK Tools:Metadata Management:

Metadata plays an important role within the SolidGroundUX ecosystem.

Version information, build identifiers, checksums, attribution information, licensing information, and other descriptive properties are maintained through a standardized metadata model.

The metadata editor provides a convenient mechanism for viewing and maintaining this information without requiring developers to update multiple files manually.

Consistent metadata improves traceability, deployment integrity, and generated documentation quality.
