Screen logging and user messages
solidgroundux_preface.sh::Framework capabilities summary:Screen logging and user messages:

The screen logging helpers provide consistent user-facing output for information, warnings, errors, success messages, debug messages, and status reporting. They reduce repeated printf boilerplate and keep scripts visually consistent.

Use the screen logging helpers whenever a script communicates with the user. This makes output easier to scan and gives all tools a shared SolidGroundUX command-line style.
