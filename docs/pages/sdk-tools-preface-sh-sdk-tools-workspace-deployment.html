Workspace Deployment
sdk tools_preface.sh::SDK Tools:Workspace Deployment:

Once development reaches a suitable stage, the workspace can be deployed.

The deployment process transforms the development workspace into an installable filesystem structure that follows the framework's expected layout.

Deployment copies the required executables, libraries, templates, documentation, configuration files, and supporting assets into their target locations while excluding development-only artifacts.

The resulting deployment structure closely resembles the environment that end users or administrators will ultimately install.
