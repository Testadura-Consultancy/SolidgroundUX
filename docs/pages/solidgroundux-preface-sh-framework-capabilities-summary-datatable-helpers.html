Datatable helpers
solidgroundux_preface.sh::Framework capabilities summary:Datatable helpers:

The datatable helpers provide functions for treating pipe-separated arrays as rows in a lightweight table-like structure. This makes it easier to pass around, inspect, and process structured row data in Bash without introducing heavier external dependencies.

Use datatable support when a script needs to work with repeated structured data, such as menu entries, generated lists, metadata rows, selection candidates, or other small tabular datasets.
