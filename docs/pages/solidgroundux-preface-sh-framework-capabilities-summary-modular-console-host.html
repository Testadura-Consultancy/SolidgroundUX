Modular console host
solidgroundux_preface.sh::Framework capabilities summary:Modular console host:

The SolidGroundUX console provides a menu-driven host application that can load independently maintained modules. Modules register menu groups and commands with the host, allowing the console to grow without hardcoding every action into one large script.

Use console modules for administrative or SDK actions that benefit from an interactive menu, especially when those actions belong to different functional groups but should remain available from one common entry point.
