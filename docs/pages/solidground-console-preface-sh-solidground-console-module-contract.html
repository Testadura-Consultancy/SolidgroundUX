Module Contract
solidground console_preface.sh::SolidGround Console:Module Contract:

A console module is a source-only Bash file.

During loading it temporarily provides:

SGND_MODULE_ID
SGND_MODULE_NAME
SGND_MODULE_VERSION
SGND_MODULE_DESC

The host validates these values, records the module, rejects duplicate module IDs, and clears the temporary metadata before loading the next module.

Modules typically follow this structure:

Define helper functions
↓
Register groups
↓
Register menu items
↓
Menu items invoke standalone executables
