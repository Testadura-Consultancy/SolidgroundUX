Target Filesystem Layout
deployment_preface.sh::First-time Installation:Target Filesystem Layout:

Installation places files into the expected SolidGroundUX filesystem layout.

User-facing commands are installed into executable locations such as bin or sbin.

Reusable libraries are installed below the framework library location.

Internal implementation scripts are installed below the framework libexec location.

Documentation, templates, configuration files, generated assets, and supporting release data are installed into their corresponding target locations.

This mirrors the target-root structure produced during release preparation and keeps deployed systems predictable.
